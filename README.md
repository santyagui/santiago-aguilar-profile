# Santiago Aguilar Silva · Perfil profesional

Perfil de una página para presentar experiencia, proyectos, formación y herramientas de Santiago Aguilar Silva, ingeniero mecatrónico en Quito.

El sitio está hecho con HTML y CSS sin dependencias externas. El archivo `index.html` contiene la página y `assets/santiago-aguilar.jpg` contiene la foto de perfil.
